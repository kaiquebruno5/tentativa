# PORTS MOBILE

Site estático em HTML/CSS/JS, pensado para celular.

## Como usar
1. Abra `index.html` no navegador para testar.
2. Para adicionar jogos, edite a lista `games` em `script.js`.
3. Cada jogo usa:
   - `name`: nome
   - `short`: texto grande da capa
   - `genre`: filtros
   - `genreLabel`: texto dos gêneros
   - `type`: origem/plataforma
   - `featured`: aparece em destaque
   - `color`: cor visual da capa
   - `link`: URL oficial

## Publicar grátis
Pode ser publicado como site estático em GitHub Pages, Netlify ou Vercel.

## Importante
O modelo usa links oficiais. Não distribua APKs, arquivos ou conteúdo protegido por direitos autorais sem autorização. Se você tiver uma fonte autorizada de distribuição, coloque a URL dela no campo `link`.
